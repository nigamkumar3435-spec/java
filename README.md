# 🚀 How to Run

## Clone Repository

```bash
git clone https://github.com/nigamkumar3435-spec/java.git
```

## Navigate to Repository

```bash
cd java
```

## Compile Program

```bash
javac FileName.java
```

```bash
java FileName
```

Example:

```bash
javac Inheritance1.java
java Inheritance1
```
